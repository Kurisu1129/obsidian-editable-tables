# 引用块内表格可编辑渲染

## Goal

引用块（blockquote）目前整段由 `MarkdownRenderer` 接管渲染：块内的表格虽然显示为 `<table>`，但是**只读的静态 HTML**——没有工具栏、不能编辑单元格。用户要求"引用块也要像正文那样渲染"，即引用块里的表格要和正文里一样，是**可编辑的表格**。

## Background

- 正文表格由 `TableWidget`（CM6 block widget）渲染为可交互网格：单元格编辑、增删行列、对齐、合并/拆分、源码跳转。
- 引用块由 `QuoteWidget` 用 `MarkdownRenderer.render()` 渲染到 `contenteditable=false` 的容器里，渲染结果中的表格只是 HTML。
- 已实测：`MarkdownRenderer` 能把引用块里的 **HTML `<table>`（带 `> ` 前缀）** 渲染成真正的表格，也能处理列表项内引用、嵌套引用中的表格。因此"扫描引用源码 → 找到表格 → 用现有表格编辑器替换渲染出的 `<table>`"在技术上可行。
- 写回是唯一的风险点：引用块内表格的源码行带 `>` 前缀（可能还有列表缩进、嵌套 `> >`），替换时必须逐行保留对应前缀，否则会破坏引用/列表结构。

## Requirements

### R1 引用块内的表格升级为可编辑表格

- 引用块渲染完成后，渲染结果中的每个 `<table>` 替换为与正文一致的表格编辑器：
  - 单元格原地编辑（单击聚焦、Enter 提交、Escape 还原）；
  - 工具栏：增删行列、列对齐、合并/拆分、源码；
  - 拖拽框选 / Shift 单击多选、合并提示与正文一致。
- 覆盖引用块内任意位置的表格：引用正文、引用内的列表项、嵌套引用（`> >`）、引用内 callout 内的表格。
- 围栏代码块中的内容不算表格（沿用现有扫描器的 fence 排除）。
- 引用块内其它内容（段落、列表、标题、代码块、嵌套引用、callout）保持现有渲染不变。

### R2 写回约束

- 编辑写回只替换**该表格对应的源码行范围**，并且每一行的引用前缀必须保留：
  - 普通引用：`> `；
  - 引用在列表项内：`  > `（列表缩进 + `>`）；
  - 嵌套引用：`> > `；
  - 引用内列表项里的表格：表格首行的完整前缀（`>   `）。
- 引用块内表格首次编辑同样按 D3 改写为 HTML 存储，并复用既有的"一次性提示"。
- 零写入不变式：打开、渲染、滚动、展开源码都必须零写入；只有用户编辑单元格或工具栏操作才写盘。
- 引用块内表格位置在文档上方发生编辑而偏移变化时，编辑必须仍落在正确范围；校验失败时**放弃写入**，绝不替换错误区间。

### R3 与引用块既有交互不冲突

- 点击、拖拽、双击表格单元格区域不能触发引用块的"拖拽选字"或"双击进入源码"。
- 引用块文本的拖拽选字 / `Ctrl+C` 复制 / 双击进入源码保持不变。
- 表格工具栏的"源码"按钮把光标放到该表格所在的引用源码处（引用整体展开为源码）。

### R4 保守降级

- 当渲染出的 `<table>` 数量与引用源码扫描出的表格数量不一致时（例如引用内嵌入了自身含表格的笔记），**整个引用块不做升级**，保持只读渲染，不做任何猜测性写回。
- 解析失败（表格语法不可解析）的表格保持只读，不渲染编辑器、不改写。

## Acceptance Criteria

- [ ] **AC29 引用块内表格可编辑**：引用块内的 pipe 表格渲染为可编辑表格；真实鼠标点击单元格、输入、Enter 后，文档中该表格被改写为 HTML，**每一行保留 `> ` 前缀**；引用块仍是同一个 blockquote；块外内容逐字节不变。
- [ ] **AC30 结构性编辑**：引用块内表格工具栏执行插入行/列后，源码前缀正确、表格在引用内重新渲染且仍是可编辑表格；Ctrl+Z 撤销恢复原状。
- [ ] **AC31 嵌套情形**：列表项内的引用块（前缀 `  > `）与嵌套引用中的表格同样可编辑并保留正确前缀；编辑不会破坏列表归属与引用层级。
- [ ] **AC32 交互无回归**：引用块文本拖拽选字、`Ctrl+C` 复制、双击进入源码（AC26）仍通过；引用块内表格区域不会触发这些行为。
- [ ] **AC33 无回归**：AC1–AC32 全部通过（正文表格、引用渲染、缩进对齐、零写入等既有断言不变）。

## Constraints

- 不引入新依赖。
- 写回仍只经 `commitGrid`（唯一写盘路径），且必须通过 `source` 校验。
- 引用块的"只读"定位改为"文本只读、内嵌表格可编辑"；除表格外不新增任何写回路径。
- 渲染阶段只读，不得因为升级表格而写盘。
- 表格编辑器与正文复用同一套交互实现，避免两套行为漂移。

## Out of Scope

- callout（顶层）里的表格接管（D6 仍推迟）。
- 引用块内表格的"新增表格"操作（只能编辑已存在的表格）。
- 引用块内表格的复制/粘贴、多表联动。
- 引用块内非表格块（如嵌套引用整体）的可编辑化。
